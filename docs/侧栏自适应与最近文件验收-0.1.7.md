# 侧栏自适应与最近文件验收（0.1.7）

日期：2026-10-15。

## 问题与原因

用户反馈非全屏窗口中看不到侧栏最近文件。旧布局中的目录按 `100vh - 164px` 独立计算最大高度，没有扣除最近文件；外层只有最小高度且隐藏溢出，最近文件被追加到可见区域下方。

通过浏览器临时注入 Git 基线样式复现：1280×600 视口、40 节长目录和 8 条最近文件时，面板实际高度 1127px，最近文件标题从 y=608.67 开始，超出窗口。数据仍在，问题发生在布局分配。

## 修改方式与作用

1. 桌面侧栏设置 `100dvh - 48px` 的明确可用高度，面板使用纵向 flex，让所有区域共同参与高度分配。
2. 目录使用剩余空间，`min-height: 0` 允许收缩；最近文件最高占面板内部高度的 35%，不再因长目录竞争而被二次压缩。最近文件少或为空时只占内容需要的高度。
3. 目录与最近列表分别内部滚动，保留最近文件标题，列表可以滚到末项；滚动边界使用 `overscroll-behavior: contain`，避免滚轮传递到正文。
4. 移动抽屉扣除顶部关闭栏后分配剩余空间。可用高度不超过 420px 时压缩装饰标题、留白与条目间距，最近文件区域上限调整为 45%，保留可操作条目。
5. 目录列表使用 ResizeObserver，在可用尺寸变化后重新检查当前项是否可见；跟随只滚目录列表，不调整正文位置。

最近文件仍仅保留在当前会话，本次没有更改保存策略。
