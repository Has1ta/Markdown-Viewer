## 发布配置

- 使用 `electron-builder` 生成 Windows x64 安装包和便携版。
- 安装包输出目录为 `release/`。
- 解压版输出目录为 `release/win-unpacked/`。
- 应用代码使用 `asar` 打包。
- 前端依赖由 Vite 打入 `dist/`，运行时不再重复携带 `node_modules`。
- `scripts/after-pack.cjs` 会在打包后保留 `zh-CN.pak` 与 `en-US.pak`，清理其他 Electron locale。
- `scripts/write-release-uninstaller.cjs` 会在 `npm run dist` 结束后整理 `release/` 辅助文件，生成 `README.txt`、`uninstall.cmd` 和 `uninstall.ps1`。
- 安装包使用 electron-builder `fileAssociations` 注册 `.md`、`.markdown`、`.mdown`、`.mkd`，安装后双击 Markdown 文件会交给 Markdown Viewer 打开。
- 由于 Windows NSIS 文件关联需要机器级安装，`nsis.perMachine` 设置为 `true`；安装时通常需要管理员权限，便携版不注册文件关联。

## 2026-06-22 打包空白页修复

问题：打包后的程序打开后只有米白色背景，菜单和关闭按钮没有反应。

原因：

- Vite 默认使用 `/assets/...` 绝对资源路径。
- Electron 生产环境通过 `file://` 加载 `dist/index.html`，绝对路径会指向磁盘根目录，导致 JS/CSS 资源加载失败。
- 前端没有启动时，主进程仍然拦截关闭并等待 `app:close-response`，所以窗口无法正常关闭。

修复：

- 在 `vite.config.ts` 设置 `base: "./"`，让生产 HTML 使用相对资源路径。
- 在 preload 暴露 `notifyReady()`，React 启动后通知主进程。
- 主进程只在渲染进程 ready 后启用未保存关闭保护；渲染进程未启动或崩溃时允许窗口直接关闭。

验证：

- `dist/index.html` 已生成 `./assets/...` 和 `./favicon.svg`。
- 打包程序通过调试端口验证出 `.app-shell`、标题、目录和正文均已渲染。
- 正常窗口关闭冒烟通过，`CloseMainWindow=True`。
