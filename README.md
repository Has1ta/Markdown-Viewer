本仓库用于管理 Markdown Viewer过程中的产品说明、界面风格规范和后续开发资料。

## 当前内容

- `项目功能与显示效果完整整理.md`：整理 Markdown Viewer 的产品定位、功能范围、界面结构和显示效果。
- `STYLE.md`：记录 Markdown Viewer 的 UI 风格指南，包括布局、字体、颜色、组件和响应式规范。
- `public/favicon.svg` / `public/app-icon.ico`：当前应用图标资源，分别用于网页标签页和 Electron 桌面程序；`public/app-icon.png` 作为同源位图备份保留。
- `软件制作方案.md`：根据项目目标整理技术路线、阶段计划、多 AGENTS 分工和验收清单。
- `AGENTS.md`：记录后续协作、维护和提交规则。
- `.gitignore`：忽略常见临时文件、依赖目录和构建产物。
- `.gitattributes`：规范文本文件换行，减少跨平台 diff 噪音。

## 项目目标

Markdown Viewer 是一款面向 Windows 桌面的 Markdown 阅读与编辑工具，强调文档优先、长文档阅读体验、渲染校对、源码精修、目录导航、本地文件保存和拖拽导入。

项目已从最初的 Electron + Vite + React + TypeScript 应用骨架推进到可打包的 Windows Markdown 阅读与编辑应用。核心 MVP 阶段（第 0–10 阶段）已完成，之后持续修复阅读、编辑和发布流程；当前源码版本为 `0.1.7`。后续功能进展和验证状态以本节及 `CHANGELOG.md` 为准。

## 开发命令

首次拉取或清理依赖后安装：

```powershell
npm install
```

启动桌面开发环境：

```powershell
npm run dev
```

执行类型检查与生产构建：

```powershell
npm run build
```

执行代码检查：

```powershell
npm run lint
```

执行 Markdown 工具函数测试：

```powershell
npm test
```

双栏浏览器回归（先在另一个终端启动 `npm run dev`，也可使用已启动的 Vite 服务）：

```powershell
npm run test:split
```

源码目录导航回归（同样需要先启动开发服务）：

```powershell
npm run test:toc
```

右侧固定切换栏与跨视图位置回归（需要先启动开发服务）：

```powershell
npm run test:views
```

以上浏览器回归通过 Playwright CLI 检查双栏编辑、源码目录、固定切换栏与跨视图定位；首次运行可能需要下载 CLI 和浏览器。截图写入 `output/playwright/`。

生成 Windows 安装包和便携版：

```powershell
npm run dist
```

安装版会注册 Markdown 文件关联，安装后可通过双击 `.md`、`.markdown`、`.mdown`、`.mkd` 文件直接用 Markdown Viewer 打开。该文件关联依赖 Windows 安装包写入系统级关联信息，因此安装时通常需要管理员权限；便携版不会自动注册文件关联。

仅检查 TypeScript 类型：

```powershell
npm run typecheck
```

## 当前源码结构

- `electron/`：Electron 主进程、preload、安全文件 API、系统菜单、拖拽路径读取、最近文件菜单和本地文件读写服务。
- `src/app/`：应用状态、类型和入口组件。
- `src/components/`：应用外壳、侧栏、最近文件、拖拽覆盖层、提示条、文档头、空状态、未保存确认弹窗和底部操作栏。
- `src/editor/`：渲染视图、CodeMirror 源码视图、Crepe 渲染编辑视图、双栏同步视图和编辑器主题。
- `src/markdown/`：标题解析、锚点生成、文档统计和 LaTeX 公式扩展。
- `src/assets/`：由源码导入并参与 Vite 打包的内置示例图片等资源。
- `src/styles/`：由 `STYLE.md` 落地的设计令牌、应用布局、Markdown 排版和响应式样式。
- `src/test-data/`：内置示例 Markdown 内容。
- `public/`：favicon 等需要保持固定根路径的公开静态资源。
- `scripts/`：打包阶段脚本，例如清理未使用 Electron locale 的 `after-pack.cjs`，以及生成 release 卸载辅助文件的 `write-release-uninstaller.cjs`。
- `tests/`：关键工具函数测试。
- `docs/`：测试、打包和发布记录。
- `output/playwright/`：阶段性浏览器截图和视觉验证记录。
- `release/`：由 `npm run dist` 生成的发布目录，包含安装包、便携版、解压版和卸载辅助入口；该目录不提交到 Git。

## 当前阶段状态

### 已完成：第 0–10 阶段（MVP 与发布基础）

- **第 0–1 阶段：项目基线与应用骨架。** 建立 Electron + Vite + React + TypeScript 工程、桌面窗口、暖白纸面风格和基础布局。
- **第 2–3 阶段：阅读渲染与目录导航。** 支持常见 Markdown 内容渲染、标题目录、层级折叠、章节定位、阅读滚动高亮和移动端目录抽屉。
- **第 4 阶段：源码编辑。** 使用 CodeMirror 6，提供语法高亮、行号、括号匹配、历史记录、软换行及焦点/失焦时清楚可见的文本选区；编辑器按需加载。
- **第 5–6 阶段：本地文件工作流。** 支持打开、保存、另存为、未保存保护、窗口关闭保护、拖拽导入及仅在当前会话保留的最近文件。
- **第 7 阶段：双栏同步编辑。** 源码编辑与 Crepe/Milkdown 渲染编辑共享同一份 Markdown，双向同步并保留滚动位置；窄屏改为上下排列。
- **第 8 阶段：代码块、图片与公式。** 代码块支持复制、语言选择与预览开关；相对图片按 Markdown 文件路径解析并为缺失图片显示占位；阅读视图支持 KaTeX 数学公式定界符 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`，双栏编辑模式启用 Latex feature，公式字体随应用打包。
- **第 9 阶段：滚动、响应式与可访问性。** 目录高亮与正文滚动联动，目录跟随限制在侧栏内部，补齐窄屏布局、键盘焦点和返回顶部入口。
- **第 10 阶段：检查与 Windows 打包。** 配置 `lint`、工具函数测试、生产构建和 `electron-builder`，可生成安装版和便携版，并附带卸载辅助文件。

### 第 10 阶段后的持续更新

- **阅读体验：** 增加固定返回顶部按钮；修复 CodeMirror 局部与跨行选区在焦点和失焦状态下不清晰的问题。
- **文件与安装：** 安装版注册 Markdown 文件关联，支持双击打开；补齐已安装版本卸载辅助入口。便携版仍通过退出后删除程序文件移除。
- **数学公式：** `0.1.2` 首次接入 KaTeX，`0.1.3` 补齐常见的 `\(...\)` 与 `\[...\]` 定界符；公式解析和字体已验证随包构建。遇到公式仍显示源码时，请确认文档使用上述任一组配对定界符。
- **双栏修复：** `0.1.4` 补齐 LaTeX 所需的 Crepe CodeMirror 插件，恢复右侧渲染；同时修复懒加载样式造成的正文过窄、异步初始化清理和紧接源码同步后的渲染侧输入丢失风险。
- **源码目录：** `0.1.5` 保持源码/双栏模式点击目录直接定位源标题，上下浏览时按当前可见章节更新目录高亮，并在编辑后同步标题行号。
- **视图切换：** `0.1.6` 将切换栏固定在右侧，切换阅读、源码、双栏时保留当前章节与章节内相对进度。
- **侧栏适配：** `0.1.7` 修复非全屏长目录挤出最近文件的问题，目录与最近文件独立滚动，缩小窗口后继续显示当前章节，窄屏抽屉和极矮窗口同步适配。
- **当前版本：** `0.1.7`。执行 `npm run dist` 会在 `release/` 生成 `Markdown Viewer Setup 0.1.7.exe` 和 `Markdown Viewer Portable 0.1.7.exe`；这些构建产物不纳入 Git。

公式语法边界：主阅读视图支持上述四类定界符；双栏 Crepe 当前支持 `$...$`、`$$...$$`，`\(...\)` 与 `\[...\]` 的解析尚未接入双栏。进入双栏不会自动替换原文的公式定界符。

## 体积优化记录

- 2026-06-21：在不缩减功能的前提下，将渲染编辑侧从 `@milkdown/crepe` 根入口改为 `CrepeBuilder` 加按需功能导入，并将 Crepe 通用样式拆为当前启用功能所需的 CSS。
- 本次优化后 `npm run build` 通过，`dist/` 中 JavaScript 总体积从约 2.861 MB 降至约 1.424 MB，CSS 总体积从约 0.099 MB 降至约 0.049 MB。
- 主要收益来自移除已禁用的 Crepe AI、Latex、内置 CodeMirror、KaTeX 字体和全量通用样式；保留源码编辑、渲染编辑、双栏同步、表格、图片块、链接提示、工具栏等现有功能。
- 2026-06-21：第十阶段打包时将运行时不需要的前端库移入开发依赖，避免 `node_modules` 重复进入 `app.asar`；打包后仅保留 `zh-CN` 与 `en-US` locale。当前安装包约 89.26 MB，便携版约 89.08 MB，`win-unpacked/` 约 309.54 MB，`app.asar` 约 1.55 MB。

## 打包问题修复记录

- 2026-06-22：修复打包后窗口只有米白色背景、菜单和关闭键无响应的问题。原因是 Vite 默认生成 `/assets/...` 绝对路径，Electron 打包后通过 `file://` 打开页面时无法加载前端 JS/CSS；现已将 Vite `base` 固定为 `./`。
- 同步增加渲染进程 ready 握手：只有 React 启动后才拦截关闭做未保存保护；如果前端启动失败，窗口仍可关闭，避免再次出现“空白且关不掉”的状态。
- 2026-06-22：`npm run dist` 会在 `release/` 中自动补充 `uninstall.cmd`、`uninstall.ps1` 和 `README.txt`，方便从发布目录直接启动已安装版本的卸载流程；便携版仍通过删除 exe 移除。
- 2026-06-22：安装包新增 Markdown 文件关联，并在主进程接收系统双击文件传入的路径；如果应用已运行，再次双击 Markdown 文件会聚焦现有窗口并按未保存保护流程打开新文件。
- 2026-06-22：页面滚离顶部后新增独立固定“返回顶部”按钮，并补充轻微淡入淡出和接近底部栏自动避让；保留底部栏原有返回顶部入口。
